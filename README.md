# 戴肥肥桌宠 DaiFeiFei

一只住在 Windows 桌面上的灰白胖猫，戴着绿围巾。免费，不联网。

- 眼睛和脑袋跟着你的鼠标，会呼吸、眨眼、摇尾巴
- 把鼠标在它头上来回摸，它会眯起眼睛打呼噜、冒爱心
- 你在任何地方滚鼠标滚轮（看网页、看代码），它就在猫抓棒上磨爪子
- 可以拖到任何地方，右键或托盘图标里可以调 7 档大小、开机自启、退出

## 下载和运行

1. 到 [Releases](../../releases) 下载最新的 `DaiFeiFei-<版本>-win-x64.zip`
2. 解压到任意文件夹，双击 `DaiFeiFei.exe`
3. 第一次打开时 Windows 可能提示“Windows 已保护你的电脑”（程序没有签名），点“更多信息”再点“仍要运行”

猫找不到了？再双击一次 `DaiFeiFei.exe`，它会回到屏幕中央。卸载就是退出后删掉文件夹，设置在 `%APPDATA%\DaiFeiFei`，也可以一起删掉。
